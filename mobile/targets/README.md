# targets/

Native Apple targets written in Swift with the `@bacons/apple-targets` config
plugin (a watch app, a widget that needs WidgetKit features `expo-widgets`
does not cover). Empty: the Home Screen widget is generated by `expo-widgets`
from `src/widgets/today-widget.tsx` (target `ExpoWidgetsTarget`, see
`../README.md` → Widget and Siri), so no Swift target is needed yet.

Identifiers derive from the app's `com.rentopya.app`:

| Target                              | Bundle id                  |
| ----------------------------------- | -------------------------- |
| Widget extension (`expo-widgets`)   | `com.rentopya.app.widgets` |
| Shared App Group (app + extensions) | `group.com.rentopya.app`   |

When a Swift target is added: `npx expo install @bacons/apple-targets`, add
`"@bacons/apple-targets"` to `plugins` in `app.json`, give the target the App
Group entitlement, and list the extension under
`extra.eas.build.experimental.ios.appExtensions` so EAS provisions it.
`Assets.xcassets` is generated on prebuild (already in `.gitignore`).
