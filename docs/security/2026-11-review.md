# Güvenlik taraması — Kasım 2026 (TEC-1170)

## Kapsam

Go API (`backend/`), panel BFF'i (`frontend/src/app/api/**`, `frontend/src/lib/server/*`) ve markalı site (`site/`):

1. HTTP middleware zinciri (`internal/httpserver/server.go`): kimlik doğrulama, `X-Organization` çözümü, şube kapsamı, step-up, panic yakalama, gövde sınırları, zaman aşımları.
2. Rate limit: giriş, OTP/SMS, şifre sıfırlama, kayıt, davet kabulü, `/v1/public/*`, `/v1/customer/{orgSlug}/*`, ödeme linkleri; SMS pompalama / maliyet istismarı.
3. CSRF: BFF'in çerezle kimliği doğrulanan istekleri, site formları, Auth.js callback'leri.
4. Çerez bayrakları (Secure / HttpOnly / SameSite).
5. CORS ve güvenlik başlıkları (CSP, HSTS, frame-ancestors, Referrer-Policy, nosniff).
6. Yükleme doğrulaması: içerik tipi koklama, aktif içerik (SVG/HTML), dosya adı / yol, sıkıştırma bombası.
7. Markalı site host çözümü, önbellek zehirleme, özel alan adı doğrulaması.
8. Kiracı izolasyonu: gövde / sorgudan alınan organizasyon veya şube kimliği, RT-A01'in kapsamadığı uuid ve token rotaları.

Daha önce kapatılanlar tekrar ele alınmadı: güvenilir proxy istemci IP'si (TEC-1163), depolama yükleme sınırı (TEC-1164), davet ele geçirme (TEC-1167), SMTP TLS (TEC-1165), config sır koruması (TEC-1130), create-super-admin varsayılanları (TEC-1169), hesap silme (PR #14), bildirim kutusu (TEC-1166).

## Yöntem

Kod okuması (rota kaydı, middleware, handler, use case ve sorgu katmanı), her bulgu için istismar senaryosu, düzeltilenler için regresyon testi. Testler `TEST_DATABASE_URL` ile (CI gibi migrate edilmiş Postgres 18) çalıştırıldı.
